# Plan: Homepage Dynamic Lists + Novel Password Protection & Encryption

## User Requirements
1. Replace "Recent Notes & Projects" on homepage with dynamic blog/novel lists (latest 3 each)
2. Add password protection to Novel section
3. Novel articles use encrypted format, only readable after password entry

## Current State Analysis

| Aspect | Current | Target |
|--------|---------|--------|
| Homepage "Recent" | Hardcoded 3 items | Dynamic: latest 3 blog + latest 3 novel |
| Novel data | Empty array `[]` | Content collection with encrypted content |
| Novel access | No protection | Password gate + client-side decryption |
| Novel content | N/A | AES-GCM encrypted, base64 stored |

## Implementation Plan

### Step 1: Create Novel Content Collection

**File: `src/content.config.ts`**
- Add `novel` collection with schema:
  ```ts
  const novel = defineCollection({
    loader: glob({ base: './src/content/novel', pattern: '**/*.{md,mdx}' }),
    schema: z.object({
      title: z.string(),
      description: z.string(),
      pubDate: z.coerce.date(),
    }),
  });
  export const collections = { blog, novel };
  ```

**Directory: `src/content/novel/`**
- Create markdown files for novels
- Content body = encrypted ciphertext (base64)

### Step 2: Encrypt Novel Content

**File: `scripts/encrypt-novel.mjs`** (one-time script)
- Use Node.js `crypto` with AES-256-GCM
- Derive key from password via PBKDF2
- Encrypt content, output base64 ciphertext
- User runs this to encrypt novel content before committing

**Password:** Use a hardcoded passphrase (configurable constant). Store only a SHA-256 hash in the frontend for verification.

### Step 3: Update Homepage

**File: `src/pages/index.astro`**
- Add `getCollection('blog')` and `getCollection('novel')` to frontmatter
- Replace hardcoded "Recent Notes & Projects" section with dynamic rendering:
  ```ts
  const blogPosts = (await getCollection('blog')).sort(...).slice(0, 3);
  const novelPosts = (await getCollection('novel')).sort(...).slice(0, 3);
  ```
- Render two sub-sections: "Latest Blog Posts" and "Latest Novel Posts"
- Each item shows: title (linked), description, date

### Step 4: Password-Protect Novel Index Page

**File: `src/pages/novel/index.astro`**
- Add password gate overlay (client-side)
- Password input with SHA-256 hash verification against stored hash
- If correct: store `sessionStorage` flag, show novel list
- If incorrect: show error message
- Session persists until browser closes

### Step 5: Novel Detail Page with Decryption

**File: `src/pages/novel/[...slug].astro`** (new)
- `getStaticPaths()` generates routes from novel collection
- Page checks `sessionStorage` auth flag
- If authenticated: render novel with decrypt button
- Encrypted content (base64) passed as prop
- Client-side decryption using Web Crypto API:
  - Import AES-GCM with PBKDF2 key derivation
  - On correct password: decrypt and render
- If not authenticated: redirect to `/novel/` or show password prompt

### Step 6: Client-Side Crypto Utility

**File: `src/lib/crypto.ts`** (shared utility)
- `deriveKey(password, salt)` → CryptoKey via PBKDF2
- `encrypt(plaintext, password)` → base64 ciphertext
- `decrypt(ciphertext, password)` → plaintext
- `hashPassword(password)` → SHA-256 hex for verification
