## Stack

- **Astro 7.x** with MDX + Sitemap integrations
- **TypeScript** (strict mode, `strictNullChecks`)
- **Node >= 22.12.0**, npm (lockfile present)
- **Deployment**: GitHub Actions (push to `main` → `actions/deploy-pages@v4`)

## Content

Collection schemas are defined in `src/content.config.ts` — the source of truth for frontmatter fields.

### Blog
Posts in `src/content/blog/` as `.md` or `.mdx`. Schema: `title`, `description`, `pubDate`, `updatedDate?`, `heroImage?` (Astro image helper).

### Novel
Posts in `src/content/novel/` as `.md` or `.mdx`. Schema: `title`, `description`, `pubDate`, `ciphertext` (AES-GCM encrypted content).

- **Slug = filename** (no extension). `first-post.md` → `/blog/first-post/`
- Posts sorted by `pubDate` descending
- **Password = UTC date** (`YYYYMMDD`). The `PASSWORD_HASH` constant in novel pages is a placeholder — auth compares the input against today's UTC date.

### Encryption workflow
1. Run `node scripts/encrypt-novel.mjs "password"` — generates SHA-256 hash and AES-GCM ciphertext
2. Paste `ciphertext` into novel post frontmatter
3. Replace `PASSWORD_HASH` in `src/pages/novel/index.astro` and `src/pages/novel/[...slug].astro` with the generated hash
4. Client-side decryption uses `src/lib/crypto.ts` (same PBKDF2 + AES-GCM params as the script)

## Architecture

- `src/pages/` — file-based routing. `index.astro` (home), `about.astro`, `blog/index.astro` (post list), `blog/[...slug].astro` (single post), `novel/index.astro`, `novel/[...slug].astro`, `rss.xml.js`
- `src/layouts/BlogPost.astro` — wraps every blog post; owns `<html>`, `<head>` via `BaseHead`
- `src/components/` — `BaseHead`, `Header`, `Footer`, `FormattedDate` (en-us locale), `HeaderLink`
- `src/lib/crypto.ts` — client-side Web Crypto helpers for novel decryption
- `src/consts.ts` — `SITE_TITLE`, `SITE_DESCRIPTION`
- `src/styles/global.css` — design tokens and base styles
- `.astro/` — generated by Astro (gitignored); do not edit

## Conventions

- Edit site-wide metadata (title, description) in `src/consts.ts`, not inline
- Date formatting is hardcoded to `en-us` in `FormattedDate.astro`
- `CLAUDE.md` is a symlink to `AGENTS.md` — edit this file only
- Matrix rain animation only appears on homepage (`src/pages/index.astro`) — not on blog/novel/about pages
- RSS feed (`rss.xml.js`) includes blog posts only — novels are excluded
- WeChat verification file: `public/27e19b3094290387249198d8fada1807.txt`
